# GitHub Copilot Instructions

## Project Context

This repository contains Tiebreak, a group polling web
application developed as a Frontend Mentor challenge.

Users can create polls, share voting links, submit votes,
manage suggestions, and view results.

Follow the existing project architecture and coding
conventions. Do not assume a specific technology stack
without checking the project files.

## Git Commit Guidelines

- Always write commit messages in English.
- Follow the Conventional Commits specification.
- Use the format: type(scope): short description.
- Use lowercase types and an imperative verb.
- Keep the subject line under 72 characters.
- Make each commit message concise and meaningful.
- Describe what actually changed, not what was planned.
- Avoid vague messages such as "update files".
- Add a short commit body when changes need explanation.
- Never invent modifications or test results.

### Allowed Commit Types

- feat: New functionality
- fix: Bug fixes
- refactor: Code restructuring
- style: Formatting or visual changes
- docs: Documentation changes
- test: Adding or updating tests
- chore: Maintenance and configuration
- perf: Performance improvements

### Examples

feat(polls): add poll creation form

fix(voting): prevent duplicate vote submissions

style(dashboard): improve mobile responsiveness

refactor(results): simplify vote counting logic

docs(readme): update project documentation

chore(config): configure development environment

## Pull Request Guidelines

- Write titles and descriptions in English.
- Explain what changed and why.
- Summarize important implementation details.
- Include testing information when available.
- Use clear Markdown formatting.
- Avoid unnecessary technical jargon.
- Never claim tests passed unless verified.

## General Development Guidelines

- Prefer clean, readable, and maintainable code.
- Follow existing naming conventions.
- Keep responsive design and accessibility in mind.
- Avoid unnecessary dependencies.
- Explain significant architectural decisions.
